Quick start

Follow the same flow a beginner would use to create a real app and begin shipping features quickly.

python -m pip install vflask
vflask new bookstore
cd bookstore

vflask module create products \
  -f name:string:required \
  -f price:decimal:required \
  -f sku:string:unique \
  -r admin -r editor

vflask run

Enterprise edge cases that matter

These are the real-world issues that separate a demo app from a platform you can trust in production.

Missing env vars
Use .env.example

Copy the environment template, fill in the required values, and never commit secrets.

Migration drift
Use Alembic

Keep schema change history explicit, reviewable, and repeatable across environments.

OAuth mistakes
Check callback URIs

Verify the exact redirect URI and confirm the client ID and secret are valid.

Duplicate package versions
Default to 1.0.0

First publish creates a missing project. Later uploads with the same version are skipped safely.

Full app lifecycle

From local development to release automation, the workflow is designed to feel like a real application framework, not a disposable starter.

Stage Command Purpose
Project setup vflask new demo Create a clean app scaffold with standard structure
Domain modeling vflask module create products -f ... Generate domain logic and tests with a compact schema
Auth and roles python -m app.cli init-db Seed roles, create tables, and ready the app for auth
Provider wiring GOOGLE_CLIENT_ID=... python -m app.cli run Connect OAuth, mail, payment, and storage through env configuration
Local run python -m app.cli run Prepare services, apply migrations, and serve the app
Testing pytest -q Validate logic and module behavior
Release python -m build + twine upload --skip-existing Publish package safely and avoid duplicate-version failures

Auth, providers, and env-first plugin flow

The framework is designed so the app logic is already implemented and the remaining work is mostly environment wiring for real credentials and provider selection.

# app runtime flow
python -m app.cli init-db
python -m app.cli run

# env-driven integrations
export GOOGLE_CLIENT_ID=...
export GOOGLE_CLIENT_SECRET=...
export GOOGLE_REDIRECT_URI=http://localhost:5000/api/v1/auth/google/callback
export PAYMENT_PROVIDER=flutterwave
export STORAGE_PROVIDER=s3
export MAIL_PROVIDER=smtp

# custom provider override
export PAYMENT_PROVIDER_CLASS=my_app.providers.CustomPaymentProvider
